## 既存フォルダへの反映

古いフォルダへFinderでマージすると重複が残るため、まず別の場所に展開して内容を確認してください。
既存のGitリポジトリへ反映する場合は、旧frontend/backend/docsを別の場所に退避してから、整理版の対応フォルダを配置します。
自分で設定済みの `.env` とGit履歴の `.git` は引き継いでください。仮想環境・node_modulesは再作成できます。
DBスキーマと業務処理は今回変更していません。既存DBの削除・初期化は不要です。
