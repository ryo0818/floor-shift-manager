# 2026-10-17 希望シフトの直接入力・パスワード6文字対応

## 希望シフト

従業員画面の各日付ボックスに、フロア・開始・終了・メモの入力欄を常時表示します。「時間帯を追加」からダイアログを開く必要はありません。

- 開始・終了は15分単位の選択式。
- フロアが1つなら自動選択して固定。複数なら選択。
- 同日の複数希望は「行を追加」で入力。
- 何も入力していない日は休み希望。ボックスを表示しただけでは希望行を作りません。
- 入力を始めた行は、開始・終了・フロアをすべて設定してから下書き保存／提出します。不要な行は「この行を削除」で消してください。
- 終了が開始以前、割り当て外、未入力の行は警告を表示し、保存・提出を止めます。
- 同日の時間重複は警告し、確認後に保存・提出可能。
- 下書き保存・半月単位の提出・締切前の再提出を維持。
- 締切後の入力変更はできません。管理者のシフト編集画面は従来どおりです。

## パスワード

新規設定するパスワードを6〜256文字に統一しました。
管理者によるアカウント作成・リセット、本人の変更、CLIの初期作成・リセットに適用します。
既存パスワードは引き続き利用できます。初回・リセット後の変更必須、ハッシュ保存、ログイン試行制限は維持します。

## 更新

追加DDLはありません。設定済みの backend/.env と公開用Nginx設定を保持して、frontend/backend のソースを更新し、両イメージを再ビルド・両コンテナを作り直してください。
既存の更新手順は [Docker更新手順](FLOOR-DELETE-UPDATE.md) を参照してください。ブラウザも強制再読み込みしてください。
過去のアカウント機能のDB更新が未実施の場合は、同手順の migrate を実行します。
